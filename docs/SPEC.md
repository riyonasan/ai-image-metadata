# Specification

EagleでPNGを1枚選び、AI Image Metadataを開くと生成情報を確認し、必要な部分をコピーできることが目的。

## Acceptance

- ポジティブ／ネガティブを細い枠と背景で区切り、折り返して3行に省略。展開でき、コピーは常に全文。
- モデル名・記録されたハッシュを個別コピー。
- LoRAは短い名前と重みを表示し、元のパス・名前・重みを含むタグをコピー。
- 生成設定は値ごとにコピー。LoRA／設定は個別に開閉。全体はEagleの見出しで開閉。
- ComfyUI優先。parametersがある場合は加工後の記録を優先。なければ対応ノードをたどり、複数経路は選択する。
- 未対応ノードで確定できないプロンプトはコピーしない。エラーは画面に示し、手動再読み込みができる。
- PNGの画像サイズと記録された生成サイズを区別する。

## Constraints

読み取り専用。外部通信、画像変更、ライブラリ更新、バックグラウンド処理なし。コピーは明示的なボタン操作だけ。永続保存はLoRA／設定の開閉状態のみ。実画像や個人データをGitに含めない。

ワークフロー表示・コピー、他画像形式、NovelAI／PixAI固有対応、全カスタムノードの再現は対象外。通常の失敗は画像を選び直すか再読み込みで復旧する。動的ノードや処理後の文字列が保存されていない場合は読み取れないことを許容する。
